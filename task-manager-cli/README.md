# Task Manager CLI

A beginner-friendly Python command-line application for managing daily tasks.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Exit the application

## Technologies
- Python 3
- Lists and dictionaries
- Functions
- Loops and conditional statements

## How to Run

```bash
python3 task_manager.py
```
